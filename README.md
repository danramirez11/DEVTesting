
# DEV Pruebas — MCP + Skills

Instrucciones rápidas para poner el proyecto en marcha.

## 1) Clonar el repositorio

Copia y pega este comando en tu terminal (reemplaza el URL por el del repo):

```bash
git clone https://github.com/danramirez11/DEVTesting.git ./
```

## 2) Entrar a la carpeta `project`, instalar dependencias y ejecutar

Copia y pega estos comandos en la terminal desde la carpeta donde clonaste el repo:

```bash
cd ./project
npm i
npm run dev
```

## 3) Entrar a la carpeta `plugin`, instalar dependencias y ejecutar

Copia y pega estos comandos en la terminal desde la carpeta donde clonaste el repo:

```bash
cd ./plugin
npm i
npm run build
```
